# pi-effect: the map

Read [How pi-effect Works](../../docs/how-it-works.md) and [Packages](../../docs/packages.md) in full before you write or change code. The first says what the library is, how its kinds of package layer, what a product supplies, and the rules that hold in every package. The second lists all fifteen packages with their entry points and READMEs.

Follow them as written: these pages are the one place these rules are kept, for people and for agents, and they
are checked against the packages. Their code is code a package's test runs, and their links lead into the READMEs,
which are the reference.

Every other page of the documentation is listed in [the overview](../../docs/index.md).
